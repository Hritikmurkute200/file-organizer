# File Organizer - Python Automation Script

## 📌 Project Description
A Python script to automatically organize files in a target directory into subfolders based on file types:
- Documents
- Images
- Videos
- Others

## ✅ Features
- Detects file types by extension
- Creates folders dynamically
- Handles errors gracefully
- Logs all activities in `file_organizer.log`

## ⚙️ Requirements
- Python 3.x
